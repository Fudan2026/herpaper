本机 · 动态服务

需要 Zotero 同步时用

双击 start.command → http://127.0.0.1:8765
  • 在静态站全部能力之上，多出一个本机后端
  • Zotero Web API v3 增量同步与 Local API 23119 桥接
  • 文献库落到本机文件，多端访问同一份数据
  • 在线只读共享链接、学术 API 代理与缓存
  • 依赖本机进程运行，关闭后仅本机不可用
技术说明：GitHub Pages 只托管静态文件，浏览器出于安全策略无法从云端页面访问本机的 23119 端口，因此 Zotero 同步与服务端持久化必须在本机运行服务时启用。若要让公网也具备动态能力，需要另接一个常驻的云端后端——这与 GitHub Pages 的静态托管是两回事。
